## Method

- Browser: Chromium 149.0.7827.55; Node v22.23.1.
- Status timing starts at the composer's submit event and ends when the browser first exposes a laid-out, visible “Understanding your request…” state. A deterministic 175 ms fixture response delay keeps the transient state observable; the delay is not included before the local status starts.
- Shell timing starts at navigation and ends on the first animation frame where the heading and enabled message composer are visible. Warm samples reuse one browser context. Cold samples disable cache and emulate 60 ms latency, 4.0 Mbps down, and 3.0 Mbps up.
- History timing starts when `/api/chat/history` is requested and ends on the first animation frame after all 50 supported messages are in the DOM. Its response-only p50/p95 are 24.40 ms / 80.70 ms; render-after-response p50/p95 are 65.90 ms / 135.00 ms.
- Asset size is the sum of deterministic gzip level 9 output for every built `.js` and `.css` file. Current raw/gzip: 71.94 KiB / 20.32 KiB.
